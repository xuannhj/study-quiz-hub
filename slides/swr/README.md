# Thư mục chứa Slide bài giảng môn SWR (Software Requirements)

Bạn có thể copy các file Slide bài giảng môn **SWR** (`.pdf`, `.pptx`, `.docx`, `.txt`, v.v.) vào thư mục này (`E:\SELF-STUDY\study-quiz-hub\slides\swr\`), hoặc gửi nội dung/đường dẫn file trong chat.

Từ các file Slide này, hệ thống/AI sẽ:
1. Tóm tắt kiến thức trọng tâm theo từng Chương vào phần **Học Lý Thuyết**.
2. Tự động tạo **Ngân hàng câu hỏi trắc nghiệm** (Luyện chương, Thi Quiz, Thi Final) kèm lời giải thích chi tiết bám sát Slide.
