# Góc học của Xuân Nhi 🍮

Không gian học tập, ôn lý thuyết và luyện quiz cá nhân hóa của Xuân Nhi — thiết kế theo phong cách **pixel-art ấm cúng**, tối giản thông tin để dễ tập trung khi ôn thi.

## ✨ Điểm nổi bật

- **Giao diện Sáng / Tối toàn màn hình:** Ban ngày nhẹ mắt với khung cửa sổ mưa rơi; ban đêm tương phản cao dịu mắt với khung phòng đêm và âm thanh nền (tiếng mưa, nhạc êm).
- **Ôn lý thuyết & Luyện thi:** Đọc kiến thức theo từng chương/bài, làm bài chế độ Ôn tập (xem giải thích ngay), Thi thử bấm giờ, hoặc ôn lại các câu còn nhớ nhầm.
- **Hỗ trợ hình ảnh & sơ đồ trực quan:** Câu hỏi có thể đính kèm hình minh họa, bảng biểu hoặc sơ đồ chuyên đề kèm chế độ phóng to chi tiết khi làm bài.
- **Động lực nhẹ nhàng:** Đồng hồ tập trung `25:00`, mục tiêu `5–7 đề/ngày`, lọ đom đóm pixel, đếm ngược 3 kỳ thi sắp tới và chuỗi ngày/giờ học tự động lưu trên trình duyệt (`localStorage`).
- **Mở rộng & Sao lưu:** Dễ dàng thêm môn mới và Import/Backup dữ liệu dạng JSON.

## 🛠️ Công nghệ sử dụng

- **Frontend:** React 18, TypeScript, React Router DOM
- **Build & Styling:** Vite 6, Tailwind CSS 3, Lucide Icons, Web Audio API
- **Kiểm thử:** Vitest, React Testing Library, JSDOM

## 🚀 Chạy tại máy

```bash
npm install
npm run dev
```

Kiểm tra test và bản build production:

```bash
npm test
npm run build
```
