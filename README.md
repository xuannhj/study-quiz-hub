## 📚 Ngân Hàng Môn Học Tích Hợp

### 1. ⚛️ FER202 — Front-End Web Development with React
* **Lý thuyết Slide & React 18/19:** 15 chương bài giảng trọng tâm, 150 câu hỏi phân tích có giải thích chi tiết tiếng Việt, 9 bộ đề thi (5 Progress Tests + 4 Final Exam Mocks).
* **Ngân hàng đề thi FE các kỳ trước:** 804 câu hỏi thực tế từ 16 đề thi FE qua 9 kỳ gần nhất (từ SP24 đến FA26 mới nhất), kèm ảnh chụp màn hình gốc và 18 bộ đề luyện phản xạ bấm giờ.

### 2. 📐 SWR302 — Software Requirements
* **Lý thuyết Slide giáo trình:** 19 chương lý thuyết bao quát toàn bộ quy trình Requirements Engineering với 118 câu hỏi trắc nghiệm trọng tâm.
* **Chuyên đề bài giảng PDF:** 6 bài giảng phân tích sơ đồ thực chiến (Use Case, Sequence, Swimlane, Data Dictionary) với 80 câu hỏi và 11 bộ đề thi chuyên biệt.
* **Đề thi FE các kỳ trước:** Hệ thống câu hỏi và đề thi thử Final Exam theo format chuẩn của trường.

### 3. 🧪 SWT301 — Software Testing
* **Lý thuyết kiểm thử (ISTQB):** 7 chương lý thuyết nền tảng (Test Levels, Techniques, Test Management...) với 150 câu trắc nghiệm và 14 bộ đề thi.
* **Đề thi thực hành PE (Practical Exam):** 8 đề thi thực chiến bấm giờ chuẩn 85 phút, đầy đủ hướng dẫn chấm điểm (Rubrics) và template nộp bài.
* **Ngân hàng đề thi FE các kỳ trước:** 627 câu hỏi trắc nghiệm qua các kỳ (SP23 đến SU26), tích hợp 80 câu đề thi thật kèm hình ảnh đề bài gốc từ phòng thi.

## ✨ Điểm Nổi Bật

* 🎨 **Không gian Pixel-Art ấm cúng:** Chuyển đổi Ngày / Đêm linh hoạt, đi kèm hiệu ứng mưa rơi, đom đóm và âm thanh Lofi thư giãn.
* ☁️ **Đồng bộ Đám mây thời gian thực (Firebase Cloud Sync):** Tự động đồng bộ tiến độ học, sổ tay câu sai và chuỗi học tập giữa Điện thoại & Máy tính chỉ với một **Mã đồng bộ cá nhân**, bảo mật và không cần tài khoản rườm rà.
* 🎯 **3 Chế độ học tập linh hoạt:**
  * **Luyện tập (Practice Mode):** Bấm kiểm tra là hiện ngay đáp án đúng/sai và lời giải thích cặn kẽ.
  * **Thi thử (Exam Mode):** Bấm giờ chuẩn phòng thi, tự động tính điểm và đánh giá Đạt / Không đạt (Pass >= 60%).
  * **Sổ tay nhớ nhầm & Flashcard (Mistake Notebook):** Tự động gom những câu từng trả lời sai, ôn luyện dạng lật thẻ Flashcard, lọc theo môn, đánh dấu Đã thuộc (*Mastered*) hoặc tạo đề thi thử thách làm lại ngay.
* 💻 **Khung hiển thị Code chuyên nghiệp:** Tự động nhận diện cú pháp mã nguồn (Java, React, SQL, HTML/CSS), phân màu chuẩn dark IDE theme với nút Copy 1-chạm.
* 📝 **Ghi chú học tập (Study Notes):** Ghi chép nhanh mẹo và công thức ngay khi làm bài mà không làm gián đoạn đồng hồ thi.
* ⏱️ **Động lực học tập bền bỉ:** Bình đom đóm mục tiêu ngày, đồng hồ tập trung Pomodoro `25:00`, đếm ngược các kỳ thi sắp tới và chuỗi ngày học liên tục (Streak).
* 💾 **Lưu trữ an toàn:** Lưu tự động trên máy khách (`localStorage`) kết hợp đám mây (`Firestore`), hỗ trợ Export/Backup dữ liệu JSON.

## 🛠️ Công Nghệ Sử Dụng

* **Giao diện & Logic:** [React 18.3](https://react.dev/), [TypeScript 5.6](https://www.typescriptlang.org/), [React Router DOM v6](https://reactrouter.com/)
* **Đóng gói & Tạo kiểu:** [Vite 6](https://vitejs.dev/), [Tailwind CSS 3](https://tailwindcss.com/), [Lucide Icons](https://lucide.dev/), Web Audio API
* **Đồng bộ dữ liệu:** [Firebase Firestore](https://firebase.google.com/) (Realtime Database Sync)
* **Kiểm thử tự động:** [Vitest](https://vitest.dev/), React Testing Library, JSDOM (100% tests passing - 54 unit tests)
* **Triển khai (Deployment):** [Vercel](https://vercel.com/) với cơ chế Single Page Application URL Rewrites

## 🚀 Chạy Mã Nguồn Tại Máy

```bash
# 1. Cài đặt thư viện
npm install

# 2. Cấu hình biến môi trường (tùy chọn cho Firebase Cloud Sync)
cp .env.example .env.local

# 3. Chạy môi trường phát triển (Local Dev)
npm run dev

# 4. Chạy bộ kiểm thử tự động (54 unit tests)
npm test

# 5. Đóng gói bản Production
npm run build
```
